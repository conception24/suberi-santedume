# 🧊 すべり三手詰め

**ニュートリーコのファンメイド、３手詰めチャレンジ。**
リポジトリ名：`suberi-santedume`

HTML / CSS / JavaScriptだけで動く静的ゲームです。`dist/` が編集対象のソース兼、そのまま配信できる完成ファイルです。ゲーム本体はビルド不要です。共有ランキングのみ、Cloudflare Pages FunctionsとD1を使います。

## 現在の公開先と配信配置

公開URL： https://suberi-santedume.pages.dev/

Cloudflare Pagesは `dist/` を公開出力とし、リポジトリ直下の `functions/` をAPIとして配信します。互換用に `dist/` の公開ファイルをルートにも同期しています。編集元は引き続き `dist/` です。ゲーム・画像・公開URL設定を変更した後は `npm run sync:root` を実行してからコミットしてください。`npm test` は両方の一致も確認します。ランキングの構成と初期設定は [docs/LEADERBOARD.md](docs/LEADERBOARD.md) に記録しています。

## 内容

- 独自生成・独立検証済みの400問。あなた→相手→あなたの3手で3個を並べます。
- デイリー：日本時間0時更新、その日・同じバージョンを開いた全員に同じ5問と応手。開始時の日付を保持するので、プレイ中の午前0時に問題が変わることはありません。失敗しても同じ問題をやり直せます。
- ランダム：別の5連勝チャレンジ。石・猫・ランダム絵文字の3種類。
- 各ラウンドは中央の「１戦目：スタート」などを押すまで待機。押してから出題配置への演出が始まり、完了後に計時します。演出中に遊び方を開いた場合は、安全にスタート待ちへ戻ります。
- 時間は考えている間だけ。演出・問題間・ダイアログ表示中・タブ非表示中は停止。ヒントの使用回数も結果に反映します。
- デイリー成績は**そのブラウザ内の `localStorage`** に保存。この個人成績はアカウントや端末間で同期されません。別途、5問完了後に任意で共有タイムランキングへ登録できます（英字1〜3文字（小文字は大文字に変換）・タイム・ヒント回数を公開）。ブラウザのデータを消すと成績も消えます。端末の日付を利用します。
- Xは投稿画面を開く方式。自動投稿しません。過去の配置画像は結果画面から別途保存できます。

## まずローカルで確認

展開した `suberi-santedume` フォルダで実行します（Python 3）。

```sh
python -m http.server 8000 --directory dist
```

ブラウザで `http://localhost:8000/` を開きます。`file://` でHTMLを直接開くと問題データの読み込みが制限されるため、HTTPサーバーを使ってください。配信に `npm install` は不要です。

現在は上記Cloudflare URLを設定済みです。公開先が決まったらNode.js 22以上で実行します。**次のURLは説明用の例**です。自分の実際のURLへ変更してください。


このスクリプトは `dist/index.html` の `og:url` / `og:image` / `twitter:image` だけを設定します。ファイルのアップロードや公開は行いません。環境変数 `PUBLIC_SITE_URL` でも指定できます。

## 公開する場合の選択肢

### A. GitHub Pages

1. GitHubへアップロードし、Settings → Pages → Source を **GitHub Actions** にします。
2. `.github/workflows/deploy-pages.yml.example` を `deploy-pages.yml` に変更してコミットします。
3. Actionsからこのワークフローの **Run workflow** を手動実行し、確認した完全な公開URLを入力します。
4. `dist/` だけが配信されます。更新時も手動実行です。単なるpushでは公開を開始しません。

リポジトリの公開設定とPagesのアクセス範囲は別途確認してください。利用条件はGitHubのプランにより異なります。[GitHub公式：カスタムワークフロー](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)

### B. Cloudflare Pages（Git連携）

GitHubリポジトリを接続し、フレームワークは **None**、ビルドコマンドは `exit 0`、出力ディレクトリは **`dist`** にします。公開URL設定済みのファイルをコミットしてから配信してください。Git連携を有効にすると、その後のpushでデプロイされる設定があるため確認してください。[Cloudflare公式：静的HTML](https://developers.cloudflare.com/pages/framework-guides/deploy-anything/)

### C. Cloudflare Pages（手動アップロード）

Direct Uploadで、`dist/` のフォルダをアップロードします。**リポジトリ全体のZIPではなく、`index.html` が配信ルートに来る `dist/` の内容**を使ってください。Direct UploadからGit連携への変更はできず、新しいプロジェクトが必要になるため、今後GitHubと連携するならBが適しています。[Cloudflare公式：Direct Upload](https://developers.cloudflare.com/pages/get-started/direct-upload/)

## テスト・生成コード

Node.js 22以上とPython 3。テストには外部依存のインストールは不要です。

```sh
npm run test:quick
python verify.py
# 盤面上のボタン配置をより広く検査する場合
npm test
```

- `test-app.cjs`：各ラウンドのスタート待ち、説明中の時計停止、中央の切替確認、ヒント連打、非同期キャンセル、5連勝、デイリー、絵文字、共有などの状態テスト。
- `verify.py`：盤面の合法性・正解初手の完全性（複数解を含む）・相手全応手・到達経路を独立検証。旧版は `python verify.py`、現行400問は `python verify.py dist/puzzles-v2.json`。
- `scripts/test-public-url.cjs`：サブパス／ルート配信、OG URL、無効入力、繰り返し設定を検査。
- テストはDOMの代替環境です。実ブラウザの見た目・音・Xリンクプレビューは公開先で別途確認してください。
- `generate.py`：問題集を再生成します。**既存の `dist/puzzles.json` を上書きします。** 問題を変える場合は `dist/app.js` の `BANK_VERSION` も変更し、全員に同じ版を配信してください。現行の到達経路データは盤面イントロに必要なので削除しないでください。
- `scripts/create-social-card.cjs`：固定画像を再生成する任意の開発ツール。生成済みPNGは同梱済みです。再生成する場合のみ `npm install` と日本語フォントが必要です。`SOCIAL_FONT_BOLD` / `SOCIAL_FONT_REGULAR` にフォントファイルのパスを指定できます（既定はLinuxのNoto Sans CJK）。フォントは同梱していません。環境により絵文字の描画は変わります。

## お気に入り

成績の横の「お気に入り」から保存一覧を開けます。5問終了後「５試合の配置を見る・保存 / お気に入り」で各問題を保存できます。保存先はこの端末・ブラウザーの localStorage（suberi-favorites-v1）です。問題集バージョンと問題 ID で重複を防ぎ、盤面と解答を含む問題データを保存します。再プレイは通常と同じ盤面・操作・効果音を使う練習モードです。通常の進行を一時退避し、一覧に戻ると元の盤面・成績・思考時間を復元します。一覧から削除できます。端末間同期はありません。

配置一覧の石・猫・絵文字はその画面内だけの切替です。各盤面の「あなた／相手」で自分の駒を確認できます。お気に入りの削除は「削除」→「本当に削除？」の二度押しで確定し、別操作や画面を閉じると確認を取り消します。

お気に入りを新しく開くと石で表示します。一覧と振り返りの間、次の登録問題へ進む間は、そのセッションで選んだ駒表示を維持し、通常モードの表示設定は変更しません。クリア後はやり直し・次の問題（登録順、末尾で停止）・一覧への復帰を選べます。共通凡例と件数を見出しに表示し、保存上の注意はⓘで開閉します。TOPは通常進行を保ったまま一時停止し、続きを再開できます。

- 新たに200問追加（正解初手1通り100問、複数100問）。旧200問はID・盤面・データを変更していません。新バンクは `puzzles-v2.json`、旧 `puzzles.json` はキャッシュ済み旧アプリの互換用に維持します。
- 「誤った初手の少なくとも一つで相手が即三目を作れる」かを実際の盤面から分類します。旧200問の15問も含む計215問が該当します。5問ごとにそのタイプを3問（75%）または4問（25%）混合し、長期的に約65%にします。全ての誤初手で即負けするとは限りません。
- ランダムは反映直後から混合。種類別のシャッフル袋と直近12問の重複回避を使います。デイリーは日本時間2026-11-04 0時から混合し、それより前の日の5問と相手の応手は旧版と一致します。開始済みのセットは日付変更でも差し替えません。
- 追加問題は正規初期配置から2～6手の合法な経路を持ちます。`scripts/generate-counter-threat.py` で再生成可能（C++17コンパイラとPython 3）。`solution` / `replies` は旧形式互換、`solutions` が全ての正解初手と応手を持ちます。ヒントは正解の一例を実演し、プレイはどの正解初手も受け付けます。
- 相手が三目を作った敗北には試遊版の下降する効果音を使用。既存の消音設定に従います。相手の三目ではクリア済みラウンドを保持し、同じ問題をやり直します（次の問題へのスキップ不可）。その他の失敗時のルールは従来どおりです。相手の三目にも自分の三目と同じ駒・ライン・紙吹雪の演出を流し、敗北説明の文章は表示しません。通常の失敗音・勝利音・5連勝音は維持。
- 既存のお気に入りのキーと内容、成績保存キーを維持。新しいデータの削除や移行は行いません。新旧タブが同日に成績を書き込んでも、問題セットの版ごとに最速記録を分離して表示します。試遊版は変更しません。

## デイリーランキング（2026-11-10追加）
